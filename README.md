**Description:** Developed an interactive web application that provides real-time visualizations of employment trends and labour market volatility across all Canadian provinces and territories.

**Data Engineering:** Engineered an automated ETL (Extract, Transform, Load) pipeline using Pandas to clean and aggregate complex datasets from various sources, ensuring data integrity for comparative analysis.

**Interactive Visualization:** Utilized Plotly and Dash to build dynamic charts and geographic maps, allowing users to perform deep-dive filtering into specific industries and regional economic shifts.

**Market Analysis:** Implemented analytical logic to derive insights from employment metrics, effectively communicating high-level labour trends through a user-friendly, responsive interface.
